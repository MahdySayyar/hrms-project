منبع: [sadprojectdocs.space-z.ai](https://sadprojectdocs.space-z.ai/)، بازبینی 2026-11-08. هر 93 اسلاید به‌ترتیب با ابزار مرورگر خوانده شد؛ [متن مشاهده‌شدهٔ هر اسلاید](slide-readings.json) از خروجی همان ابزار در این گفت‌وگو حفظ شده است. دریافت مجدد یا خلاصهٔ چند اسلاید مبنای این export نیست.

[جدول تطبیق 93 اسلاید](../../project-framework-slide-review.md) نشان می‌دهد هر موضوع کجا در HRMS اعمال یا برای review/آزمایش آینده باز مانده است. بعضی مثال‌ها captionهای بازاستفاده‌شده، کلید decision تکراری در YAML و تفاوت Rubric دارند؛ این ایرادها در مدارک HR تکرار نشده‌اند.
