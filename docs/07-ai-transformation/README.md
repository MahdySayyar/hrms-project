# AI-CAT-01 — استفادهٔ ثبت‌شده از عامل کدنویسی

عامل فعلی Codex مبتنی بر GPT-6 است؛ شناسهٔ دقیق build و temperature در این محیط افشا نشده‌اند و حدس زده نمی‌شوند. تاریخ ثبت 2026-11-08. دانشجو مالک تحلیل/تصمیم/پذیرش است؛ تولید مدارک یا عبور آزمون توسط عامل، جای بازبینی دانشجو نیست.

| شناسه | کار واقعی | ورودی در زمان کار | خروجی و اعتبارسنجی |
|---|---|---|---|
| TRF-01 | specification و اصلاح گردش تصمیم درخواست، CR-01 | درخواست مستقیم کاربر، کد موجود، UC-02 و ADR-04، آزمون پیش از اصلاح | Domain/Service/Repository و route؛ 16/17 قبل و 17/17 بعد |
| TRF-02 | حذف وابستگی clock سرویس به ORM module | prompt ثبت‌شده، ARCH-SPEC-01، UC-02، CMP-01 و CLS-01 | service با UTC stdlib، مرز stricter؛ 29/29 و coverage 96.6٪ |

رکوردهای ماشین‌خوان در [transformation-records](transformation-records/TRF-01.yaml) و [TRF-02](transformation-records/TRF-02.yaml) قرار دارند. [پرامپت TRF-02](prompts/TRF-02.txt) پیش از اصلاح محدود نوشته و توسط همین عامل اجرا شد. [درخواست کاربر](prompts/TRF-01-user-request.txt) مبنای TRF-01 است؛ یک prompt تاریخی تفصیلی یا بازبینی دانشجو جعل نشده است.

محدودیت ترتیب: کد اولیهٔ گسترده قبلاً ساخته شده بود؛ مدل‌های دامنه/رفتاری این نوبت عمدتاً reconstruction هستند. UC-02 و آزمونِ conflict قبل از تغییر کد ثبت شدند؛ تمام مدل‌ها قبل از TRF-01 وجود نداشتند. برای TRF-02 مدل/طرح و prompt پیش از تغییر موجود بودند. بازسازی مستندات را به عنوان اجرای تاریخی همهٔ Milestoneها گزارش نمی‌کنیم.

خروجی source diff در outputs/ حفظ می‌شود. این خروجی‌ها فقط فایل‌های مرتبط با task را شامل می‌شوند و جای رونوشت کامل مکالمه نیستند. هیچ اسم، مشارکت، مصاحبه، student modification یا امضای قبول برای افراد ساخته نشده است. [چک‌لیست بازبینی](ai-review.md) مرحلهٔ انسانیِ باز را مشخص می‌کند.

نمونه‌های ارائه از دامنهٔ غذا، فقط الگوی سندند. idempotency بیرون transaction یا emit یک رویداد پیش از commit، به‌تنهایی تضمین نیست؛ کد HR برای تصمیم از قفل/تراکنش واقعی استفاده و audit failure را آزمون می‌کند. Outbox/queue/event delivery هنوز پیاده نشده‌اند.
