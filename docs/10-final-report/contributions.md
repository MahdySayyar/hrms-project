# CONTRIB-01 — ثبت مشارکت واقعی

نام اعضا، تعداد تیم و تقسیم مسئولیت واقعی اعلام نشده است. نقش‌های هشت‌گانهٔ اسلایدهای 24 و 63 صرفاً چارچوب‌اند؛ هیچ نام، مصاحبه، review یا commit انسانی برای پرکردن جدول ساخته نشده است.

| مسئولیت پیشنهادی | فرد و شواهد |
|---|---|
| راهبری پروژه و نیازمندی | تعیین نشده؛ artifact/commit/review واقعی ثبت شود |
| مدل‌سازی | تعیین نشده |
| معماری و ADR | تعیین نشده |
| طراحی تفصیلی | تعیین نشده |
| AI transformation | تعیین نشده |
| پیاده‌سازی | تعیین نشده |
| آزمون و کیفیت | تعیین نشده |
| مستندات و traceability | تعیین نشده |

شاهد فعلیِ مشخص: عامل Codex کد و مدارک این نوبت را تولید/بررسی کرده و commit محلی با author عامل ثبت می‌شود. این شاهد، مشارکت دانشجو نیست. تغییرات دستی دانشجو گزارش نشده‌اند. اعضا باید cross-functional باشند و بتوانند زنجیرهٔ کامل را توضیح دهند؛ یک role اختصاصی، بقیه را از شناخت مدارک معاف نمی‌کند.

برای هر مشارکت واقعی: نام، تاریخ، artifact/version، شرح کار، لینک commit یا review، نتیجه و در صورت استفاده از AI شناسهٔ TRF ثبت شود. قالب تهی، contribution انجام‌شده محسوب نمی‌شود.
