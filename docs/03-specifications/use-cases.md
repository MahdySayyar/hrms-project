# UC-CAT-01 — کاربردها و قراردادهای کامل

وضعیت: بازسازی Core فعلی و specification اصلاح CR-01؛ بازبینی انسانی باز است. سند اصلی ماشین‌خوان در specs نگهداری می‌شود.

| شناسه | کاربرد | بازیگر | هدف و مرجع |
|---|---|---|---|
| UC-01 | ورود و پایان نشست | admin / hr / viewer | [مشخصات کامل](../../specs/UC-01.yaml)، SEQ-01، ACT-01، ST-01 |
| UC-02 | ثبت و تصمیم درخواست HR | hr یا admin برای ثبت؛ admin برای تصمیم | [مشخصات کامل](../../specs/UC-02.yaml)، SEQ-02، ACT-02، ST-02 |
| UC-03 | محاسبه و حفظ فیش آموزشی | admin | [مشخصات کامل](../../specs/UC-03.yaml)، SEQ-03، ACT-03، ST-03 |
| UC-04 | پرونده/وضعیت/جست‌وجوی کارمند | hr / admin | FR-04..06؛ فهرست کاربرد، هنوز specification تفصیلی مستقل ندارد |
| UC-05 | اطلاعات سازمان | hr / admin | FR-07 |
| UC-06 | متقاضی، مصاحبه، استخدام و پذیرش | hr / admin | FR-08..10 |
| UC-07 | شیفت و تردد | hr / admin | FR-11 |
| UC-08 | قرارداد، تمدید و خاتمه | hr / admin | FR-17 |
| UC-09 | ارزیابی، آموزش و مسیر شغلی | hr / admin | FR-18..20 |
| UC-10 | تاریخچهٔ انتساب | hr / admin | FR-21 |
| UC-11 | گزارش کلی و خروجی CSV | viewer / hr / admin؛ CSV فقط hr/admin | FR-22..23 |
| UC-12 | مشاهدهٔ ممیزی و مدیریت حساب | admin | FR-24..25 |

UC-01 تا UC-03 شامل trigger، بازیگر، پیش‌شرط، ورودی، جریان، خطا، موفقیت/شکست، قواعد و پیوند آزمون‌اند. محدودیت تاریخ و نرخ آموزشی بخشی از specification است.

قرارداد تصمیم مخالف در UC-02 نسخهٔ ۲ پیش از اصلاح کد ثبت شد. مدل‌های رفتار موجود و مدارک گسترده‌تر پس از ساخت کد اولیه بازسازی شدند؛ ادعای اجرای همهٔ M1 تا M5 پیش از کد تاریخی نداریم. برای تغییرات آینده ابتدا specification/model/ADR تغییر می‌کند، سپس آزمون و پیاده‌سازی.
