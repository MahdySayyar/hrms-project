# ADR-26 — نمایش مستقیم هشت حوزه

بازخورد کاربر نشان داد منوی جمع‌شونده و صفحهٔ حساب، پیدا کردن قابلیت‌ها را دشوار می‌کردند. طرح پیش از اصلاح ثبت شد. مدیر هشت حوزه را مستقیماً در منو و صفحهٔ همهٔ بخش‌ها می‌بیند. هر حساب می‌تواند نمای معرفی هشت حوزه را باز کند. دکمهٔ ورود به هر حوزه به نقش موجود وابسته است و نقش کاربر عادی فقط معرفی قابلیت‌ها را می‌بیند. نما هیچ گزارش یا رکورد سازمانی نمی‌خواند. بازبینی انسانی در انتظار است.
