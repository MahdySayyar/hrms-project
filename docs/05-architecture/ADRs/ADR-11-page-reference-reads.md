# ADR-11 — خواندن دسته‌ای نام منابعِ صفحه

تاریخ 2026-11-17؛ طرح پیش از اصلاح کد همین گام، بازبینی انسانی در انتظار. صفحه‌بندی و قواعد موجود از کد فعلی بازسازی شده‌اند؛ این سند تحلیلِ پیش از پیاده‌سازی تاریخی آن‌ها نیست.

## مسئله و شاهد

در `modules.module_list` پس از count و LIMIT/OFFSET، `display_value` برای هر سلولِ دارای شناسه `db.get` اجرا می‌کند. مرجع‌های نمایش نگهداری نمی‌شوند؛ identity map ضعیف SQLAlchemy تضمین cache برای سلول بعد نیست. سقف صفحه، هزینهٔ وابسته به تعداد سلول‌ها را حذف نکرده است. [پروتکل اندازه‌گیری](../../../scripts/measure_read_paths_20261117.py) سه فهرست و اندازه‌های 1/50/100 را با PostgreSQL ساختگی، شمار SELECT و HTML یکسان بررسی می‌کند.

## تصمیم و قرارداد

پس از تعیین صفحهٔ مجاز، شناسه‌های متمایزِ ستون‌های نمایشی جمع شوند. برای هر نوع مرجع فقط یک `SELECT id,label WHERE id IN (...)` اجرا شود؛ نقشهٔ محلی در همان فراخوانی route مصرف شود. ستون‌های لازم نام/عنوان‌اند؛ رمز، کد ملی، تلفن یا پروندهٔ کامل برای برچسب خوانده نشوند. `display_value` در مسیر جزئیات همان fallback قبلی را داشته باشد. ردیف‌های اصلی و count همچنان از query دارای نقش، محدوده و فیلتر می‌آیند.

هدف قابل آزمون: SELECTهای نام منابع با نوع مرجع رشد کنند، نه با تعداد ردیف؛ برای مرخصی/متقاضی 4 SELECT و تردد 5 SELECT شامل auth/count/page، در صفحهٔ 1 تا 100 ردیف. صفحهٔ خالی query مرجع نخواهد داشت. optional/null، مرجع گم‌شده، نام مشترک، ترتیب، HTML escaping و برچسب‌ها حفظ شوند. تغییر نام در HTTP request بعد دیده شود.

این نقشه cache بین درخواست‌ها نیست؛ TTL و invalidation تازه لازم ندارد. فرایند و PostgreSQL مشترک و مرز اختصاصی Domain/Service/Repository تصمیم درخواست حفظ می‌شوند.

## اثر و بازگشت

تغییر در `app/modules.py` و آزمون‌های مستقل فهرست. schema، endpoint، پارامتر، کوکی، مجوز و قالب عوض نمی‌شوند؛ مهاجرت داده یا deployment لازم نیست. بازگشت با حذف helper و برگرداندن همان فراخوانی `display_value` از [snapshot پیش از بررسی](../../snapshots/architecture-review-baseline-20261117-b.json) ممکن است؛ فایل‌های نامرتبط و تغییرهای قبلی نباید reset شوند.

آزمون مثبت/منفی/مرز و اندازه‌گیری قبل/بعد برای همین گام لازم‌اند. فرم‌های GET با گزینه‌های کامل و فهرست محاسبهٔ حقوق مسئلهٔ جدا هستند؛ بهبود این گام ظرفیت 500 کاربر را اثبات نمی‌کند.
