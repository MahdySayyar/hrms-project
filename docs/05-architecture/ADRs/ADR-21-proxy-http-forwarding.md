# ADR-21 — انتقال مسیر کدشده و متادیتای پاسخ پراکسی

در بازبینی 2026-11-17 مشخص شد پراکسی مسیر decode‌شده را دوباره به URL بالادست می‌چسباند. نویسهٔ کدشدهٔ `%3F` می‌تواند به جداکنندهٔ query و `%23` به fragment تبدیل شود. پراکسی همچنین طول پاسخ HEAD یا 304 را از بدنهٔ خالی محاسبه می‌کرد و برای 204 هدر طول می‌ساخت.

طرح پیش از اصلاح ثبت شد. پراکسی مسیر و query خام ASGI را به بالادست می‌فرستد. Content-Length معتبر پاسخ HEAD و 304 از بالادست می‌آید، 204 آن را ندارد و طول پاسخ عادی از بایت‌های بدنه محاسبه می‌شود. پاک‌سازی هدرهای Connection، کوکی‌ها، affinity و عدم تکرار درخواست حفظ می‌شوند. آزمون TC-01-07 مسیر شامل نویسه‌های رزروشده و پاسخ‌های بدون بدنه را پوشش می‌دهد. بازبینی انسانی و Gate در انتظارند.
