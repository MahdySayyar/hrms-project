# ADR-22 — کاهش رفت‌وبرگشت پایگاه داده در داشبورد

طرح پیش از پیاده‌سازی ثبت شد. صفحهٔ اصلی چهار شمارش جداگانه و برای نقش‌های HR و مدیر یک SELECT کامل از آخرین پنج پرونده دارد. یک SELECT با شمارش شرطی کارکنان و دو زیرپرس‌وجوی مستقل سازمان جایگزین چهار درخواست می‌شود. فهرست پنج‌تایی فقط شناسه، نام، کد و وضعیت را می‌خواند. دامنهٔ شمارش شعبه و واحد، نقش‌ها، ترتیب، تازه‌خوانی درخواست بعدی و رفتار سازمان خالی حفظ می‌شوند. TC-04-09 تعداد SELECTها و خروجی نقش‌ها را مقایسه می‌کند. بازبینی انسانی در انتظار است.
