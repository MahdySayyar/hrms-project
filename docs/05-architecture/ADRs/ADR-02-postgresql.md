# ADR-02 — PostgreSQL به‌عنوان پایگاه مشترک

تاریخ ثبت 2026-11-08؛ وضعیت: انتخاب موجود بازسازی‌شده، تأیید انسانی باز. پیوندها: DM-01، DB-01، BR-05/06/10/13/14.

مسئله: پرونده، انتساب، قرارداد، درخواست و audit روابط و تغییرات اتمیک دارند. آموزش آزمایش replica در ارائهٔ مقیاس‌پذیری نیز PostgreSQL را مبنا می‌گیرد.

گزینه‌ها: PostgreSQL با قید مرکب/partial unique index/قفل ردیف؛ SQLite با استقرار ساده‌تر ولی رفتار هم‌زمانی متفاوت؛ MongoDB با مدل سند ولی نیاز بیشتر به طراحی روابط و قیدها.

تصمیم موجود: PostgreSQL 17.6 محلی با SQLAlchemy و psycopg. یک پایگاه مشترک و ۲۱ جدول؛ schema آزمون مستقل در همان نمونه. نسخهٔ واقعی و ساختار در DB-01 صادر می‌شود. JSON مربوط به snapshot از نوع JSON است؛ آن را JSONB نمی‌نامیم.

آثار: تضمین uniqueness و تراکنش واحد؛ وابستگی دسترس‌پذیری وب به همین پایگاه؛ یک نقطهٔ خرابی، بدون replication و failover. آزمون همروندِ تأیید و rollback audit روی PostgreSQL واقعی اجرا شده است؛ آزمون SQLite معادل آن نیست.
