# ADR-03 — کوکی نشست و حافظهٔ یک پردازه

تاریخ ثبت 2026-11-08؛ وضعیت: انتخاب موجود بازسازی‌شده، تأیید انسانی باز. پیوندها: UC-01، ST-01، NFR-S-01 و آزمایش آیندهٔ EXP-05.

گزینه‌ها: نشست حافظه‌ای و کوکی opaque؛ JWT خودبسنده؛ نشست مشترک در Redis یا پایگاه. حافظهٔ محلی برای مبنای یک‌پردازه‌ای ساده است. JWT نیاز به مدیریت ابطال/انقضا و CSRF مناسب جریان مرورگر دارد. Redis وابستگی عملیاتی و سیاست خرابی جدید ایجاد می‌کند.

تصمیم موجود: PBKDF2-SHA256 با 600000 iteration، token تصادفی، انقضای نشست، چرخش کوکی بعد از login، HttpOnly و SameSite=Lax، CSRF در POST. COOKIE_SECURE در HTTP محلی false است. TLS عمومی و SSO ساخته نشده‌اند.

آثار و بررسی: خروج و حساب غیرفعال دسترسی را قطع می‌کنند؛ restart حافظه را از بین می‌برد. چند worker/replica با این نشست هنوز پشتیبانی صحیح ندارد. این محدودیت باید ابتدا در EXP-05 مشاهده و سپس با نشست مشترک اصلاح شود. نشست محلی را stateless نمی‌نامیم. هیچ رمز یا token واقعی در خروجی مهندسی ذخیره نمی‌شود.
