# ADR-23 — کاهش پیمایش نشست‌های حافظه‌ای

طرح پیش از پیاده‌سازی ثبت شد. در حالت حافظه‌ای، ایجاد هر کوکی ناشناس تمام نشست‌های موجود را زیر قفل بررسی می‌کند. پاک‌سازی سراسری حداکثر یک‌بار در هر ۳۰ ثانیه، هنگام درج یا چرخش نشست، انجام می‌شود و در صورت توقف فعالیت پیمایش جداگانه‌ای وجود ندارد. انقضای همان نشست همچنان در هر خواندن و چرخش بررسی و هنگام دسترسی اعمال می‌شود. ابطال آنی باقی می‌ماند و Redis تحت این تغییر قرار نمی‌گیرد. اندازه‌گیری با نشست‌های ساختگی و آزمون زمان کنترل‌شده انجام می‌شود. بازبینی انسانی در انتظار است.
