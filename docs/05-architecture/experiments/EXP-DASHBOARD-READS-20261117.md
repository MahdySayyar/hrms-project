# کاهش خواندن‌های داشبورد

[ADR-22](../ADRs/ADR-22-dashboard-reads.md) طرح شمارش شرطی و واکشی فیلدهای نمایش را پیش از اصلاح ثبت کرد. [آزمون قبل](../../08-testing/evidence/dashboard-reads-before-20261117-a.json) با ۱۲۳ کارمند ساختگی، ۶ SELECT برای مدیر و کارشناس و ۵ SELECT برای مشاهده‌گر ثبت کرد. این تعداد شامل یک پرس‌وجوی احراز هویت است.

در [آزمون بعد](../../08-testing/evidence/core-runtime-speed-20261117-a.json)، تعداد به ۳ SELECT برای مدیر و کارشناس و ۲ SELECT برای مشاهده‌گر رسید. شمارش سازمانی در محدودهٔ نقش ماند و آخرین پنج پرونده برای نقش مجاز به ترتیب قبل نمایش داده شدند. مشاهده‌گر فهرست پرونده دریافت نکرد. SELECT فهرست فقط شناسه، نام، کد و وضعیت را می‌خواند. کاهش رفت‌وبرگشت SQL اندازه‌گیری شد. زمان پاسخ در زیرساخت دیگر و بازبینی انسانی هنوز بررسی نشده‌اند.
