# اجرای مرحله‌ای معماری

درخواست کاربر در 2026-11-08: کارهای باز، یک‌به‌یک اجرا شوند. مبنا commit `e61ac2c` و آرشیو مستقل framework-release-20261108 است. این پوشه دفتر اجرای واقعی است؛ برنامهٔ آینده در [نقشهٔ آزمایش‌ها](../progressive-experiments.md) و قرارداد قابل بازتولید در [EXP-PROTOCOL-01](../../../specs/scalability-experiments.yaml) قرار دارد.

ترتیب اجرا: ظرفیت native → رفع گلوگاه مشاهده‌شده → کانتینر مشترک → Compose و پایش → چند نمونه و خرابی → نشست مشترک → کش/replica → کنترل ورود → صف/worker → بازیابی و تکمیل مدارک.

برای هر مرحله: نسخهٔ مبنا، مسئله و فرضیه، تغییر محدود، بار/داده/منابع، نتیجهٔ قبل و بعد، آزمون صحت/خرابی، ADR و محدودیت ثبت می‌شود. فایل پیکربندی آماده، بدون اجرای واقعی، «اجراشده» محسوب نمی‌شود.

## شروع اجرا

Docker و kubectl نصب‌اند؛ شروع موتور Docker درخواست شد. بررسی اولیهٔ WSL نبودن فایل kernel را گزارش کرد. مشخصات میزبان: Windows 10، پردازندهٔ i7-6700HQ، 4 هسته/8 پردازندهٔ منطقی، حدود 23.9 GiB RAM. این وضعیت نیازمند کنترل پس از شروع Docker است؛ مانع محیطی و نتیجهٔ آزمایش جدا ثبت می‌شوند.

ابزار ظرفیت جدید، زمان شروع steady را پس از آماده شدن کاربران تعیین می‌کند، مصرف منابع و اتصال‌های پایگاه را می‌سنجد و حجم پاسخ فهرست‌ها را ثبت می‌کند. آزمون‌های موجود و دادهٔ واقعی دست‌نخورده‌اند.

[بازبینی انتقال HTTP](EXP-PROXY-HTTP-REVIEW-20261117.md) شکست مسیر کدشده و بررسی پاسخ‌های بدون بدنه را ثبت می‌کند.

[ساخت حساب کاربری](EXP-ACCOUNT-REGISTRATION-20261117.md) ثبت از صفحهٔ ورود و فعال‌سازی توسط مدیر را پوشش می‌دهد.

[نشست مشترک Redis](EXP-SHARED-SESSIONS-20261117.md) انتقال نشست، restart وب و ابطال نشست روی وب دیگر را ثبت می‌کند.

[بهینه‌سازی Argon2id](EXP-ARGON2-LOGIN-20261117.md) زمان بررسی رمز و نتایج سه تکرار آزمون 500 ورود را ثبت می‌کند.

ورود هم‌زمان 2026-11-17: [افزایش وب‌ها](EXP-LOGIN-REPLICAS-20261117.md)، [صف خصوصی رمز](EXP-LOGIN-PASSWORD-20261117.md) و [اتصال proxy و شاهد نهایی](EXP-LOGIN-PROXY-20261117.md) شکست‌ها و نتیجهٔ هر گام را جدا ثبت می‌کنند. 500/500 ورود و نشست، 830/830 probe موفق، restart صفر؛ زمان کل ورودها حدود 107s روی همین میزبان است. این آزمون پذیرش بار ترکیبی پنج‌دقیقه‌ای یا HA نیست.

[اجرای نسخهٔ دانلودی](EXP-DOWNLOAD-20261117.md) launcher بدون Python میزبان و آزمون کپی تازه با project/volume ساختگی جدا را ثبت می‌کند.

[Docker Compose](EXP-DOCKER-COMPOSE.md) اجرای واقعی دو کانتینر، تست PostgreSQL و حفظ volume را در 2026-11-16 ثبت می‌کند.
