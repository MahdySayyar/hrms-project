# EXP-05 — جابه‌جایی نشست بین وب‌ها

[ADR-19](../ADRs/ADR-19-shared-sessions.md)، [UC-01](../../../specs/UC-01.yaml) و [مدل توالی](../../../models/design/shared-login.mmd) قرارداد نشست مشترک را ثبت می‌کنند. آزمایش روی یک رایانه، دو وب مستقل در Docker و یک PostgreSQL با schema ساختگی انجام شد. بازبینی انسانی و Gate در انتظارند.

در [اجرای نشست حافظه‌ای](../../08-testing/evidence/sessions-memory-before-20261117-b.json)، همان کوکی روی وب دوم به صفحهٔ ورود برگشت (303). اجرای راه‌اندازی مجدد در این آزمایش به خطای اتصال رسید. بررسی اسکریپت نشان داد bootstrap آزمایش در restart دوباره تلاش می‌کرد schema موجود را بسازد. bootstrap فقط برای schema تصادفی و اختصاصی آزمایش قابل تکرار شد.

[آزمون کنترل با bootstrap اصلاح‌شده](../../08-testing/evidence/sessions-memory-control-20261117-a.json) نشان داد همان کوکی پس از انتقال به وب دوم و بعد از restart وب اول در حالت حافظه‌ای دوباره به صفحهٔ ورود می‌رسد (303).

در [آزمون Redis](../../08-testing/evidence/sessions-redis-after-20261117-b.json)، ورود روی وب اول موفق بود. همان کوکی روی وب دوم و بعد از restart وب اول به داشبورد رسید (200). خروج از وب دوم دسترسی روی وب اول را قطع کرد و کوکی ناشناس قبلی هم دسترسی نداشت. همهٔ بررسی‌ها موفق شدند و کانتینرها و volume آزمایش حذف شدند. [آزمون‌های قراردادی](../../08-testing/evidence/fast-login-contracts-20261117-a.json) انقضا، ابطال، چرخش اتمی و خطای مخزن نشست را نیز پوشش می‌دهند.

در [کپی تازهٔ نسخهٔ قابل دانلود](../../08-testing/evidence/github-download-shared-20261117-a.json)، راه‌انداز PowerShell چهار وب و Redis را بالا آورد. ۱۸ بررسی نصب، ورود، CSRF، حفظ رمزها، و ماندگاری دادهٔ ساختگی پس از توقف و شروع دوباره موفق بودند. [مجموعهٔ اصلی داخل Docker](../../08-testing/evidence/core-docker-github-download-shared-20261117-a.json) و [رگرسیون](../../08-testing/evidence/regression-docker-github-download-shared-20261117-a.json) نیز موفق شدند.

Redis نشست را در حافظه نگه می‌دارد. restart وب نشست را حفظ می‌کند و restart Redis ورود مجدد می‌خواهد. خرابی Redis به 503 منتهی می‌شود. اجرای چند دستگاه فیزیکی و دسترس‌پذیری بالا بررسی نشده‌اند. [راهنمای استقرار چند دستگاه](../../../deployments/README.md#اجرای-وب-روی-دستگاههای-مستقل) تنظیمات مشترک و الزامات ورودی را توضیح می‌دهد.
